# Clearspace public pages

Static HTML and shared CSS. Upload this directory's contents to your website host. Keep these files separate from the extension ZIP.

- `index.html`: homepage
- `support.html`: setup, troubleshooting, support contact
- `privacy.html`: privacy policy for the current implementation
- `site.css`: shared responsive design; no external dependencies

Before publishing:
1. Replace the visible contact placeholders in support.html and privacy.html with your publisher name and working contact email or support URL.
2. Add your actual Chrome Web Store link to the homepage when your listing is available.
3. Review the privacy policy against the exact version you submit. If your host uses additional analytics/cookies, disclose those.
4. Enter your published HTTPS URLs in the dashboard: homepage `/`, support `/support.html`, and privacy `/privacy.html`.

These files are prepared locally; creating them does not publish a website.
